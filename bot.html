secureme-scanner

SecureMe operates an external attack-surface scanner that checks whether our customers' own systems are publicly exposed.

Every request from us identifies itself as:

secureme-scanner/<version> (+https://secureme.space/bot)

Every request also carries a From: header set to abuse@secureme.space.

Our scanner only ever connects from IP addresses listed in ranges.txt. If a request claims to be us but comes from outside those ranges, it is not us — please report it.
